# 参考资料：87 版《红楼梦》实景（北京大观园 / 上海大观园）

用途：给 3D 复原的 loop 迭代提供可建模的视觉事实。**优先级：原著文字 > 北京大观园（为 1987 年央视版专门修建）> 上海大观园 > 通用清式做法。** 剧照和景区照片只能作为参考，不能放进 web 构建。本地参考图在 `research/tv86/`，来源见 `research/tv86/SOURCES.md`，均为 Wikimedia Commons 上的 CC BY / CC BY-SA 图片。

## 背景（有出处）
- 北京大观园 1984 年始建，1986 年开放，1988 年三期完工。央视为拍《红楼梦》而建，总设计师杨乃济，经红学、古建、园林、清史、民俗专家论证。总面积 12.5 公顷，建筑 8000 余平方米，水面 2.4 万平方米，景点 40 余处。来源：http://www.visitbeijing.com.cn/article/4K465UJqkdU ，https://r.visitbeijing.com.cn/attraction/86 ，https://www.tsinghua.edu.cn/info/1181/53476.htm
- 砖木结构，油饰按清代工艺。彩画为“金线苏彩”，仅金线就用了黄金八十两。来源：同上（visitbeijing），以及 https://gs.ctrip.com/html5/you/travels/1/4158352.html
- 整体风格：“兼有皇家林苑气派和江南园林秀丽”，讲究“遮掩”；“一进大观园，首先映入眼帘的便是绿柱灰顶的回廊，和喜庆的红灯笼”。来源：https://www.visitbeijing.com.cn/article/47QkiNuVe92 ，https://m.sohu.com/a/1010196645_121792335
- 上海大观园（青浦淀山湖畔，1981–1988）以大观楼为主体，中轴线依次为“省亲别墅”石牌坊、石灯笼、沁芳湖、体仁沐德、曲径通幽、宫门、“太虚幻境”浮雕照壁、木牌坊；“古树名木与朱柱粉墙相互衬托”。来源：https://m.maigoo.com/citiao/116279.html ，https://gs.ctrip.com/html5/you/travels/2/3974677.html

## 全局样式表（建模用）

| 瓦当 / 勾头滴水 | 檐口一排圆形勾头，下垂三角滴水，灰色 | ref02, ref04 |
| 连檐、瓦口、椽头 | 朱红连檐 `#b0362a`。飞椽头绿底 `#2f6b4f` 带白点，檐椽头青蓝 `#2b4f7a` 带金圈：檐口看上去是一条“红 + 蓝绿点阵”的彩带 | ref02, ref05 |
| 柱 | 主体建筑为朱红 `#a3302a`；回廊和潇湘馆一类为绿柱 `#2e6a4a`（“绿柱灰顶的回廊”）；稻香村为本色木 `#7a5a3a` | ref04, ref09 |
| 额枋彩画（苏式） | 底色青 `#2d5a8a` 和绿 `#2f7a5a` 交替。中部是“包袱”：白底或浅黄底的半圆框，内画山水花鸟。箍头、卡子描金 `#d4a640` | ref05, ref09 |
| 倒挂楣子 / 坐凳楣子 | 柱间额枋下有一条绿色或红色的步步锦楣子，两端带雀替（金线、红蓝） | ref02, ref05, ref09 |
| 隔扇门 / 槛窗 | 朱红或绿色框。上部为灯笼框或步步锦棂心，糊白纱 `#f2efe6`；下部裙板加绦环板，描金 | ref02, ref05, ref11 |
| 院门（怡红院） | 垂花门式，三开间。绿色大门 `#2f6b4f` 配红框；黑底金字横匾 `#1a1a1a` / `#d4a640` | ref05 |
| 墙 | 白粉墙 `#efede6`，下碱为青砖 `#7d8186`，墙顶筒瓦压顶。圆洞门用青砖磨砖门套，门上嵌石刻匾 | ref05, ref12 |
| 台基 / 栏杆 | 青白石 `#d8d6cf`（“房山青白石”）。踏跺 3–5 级；月台加石栏 | ref04, ref11 |
| 匾额 | 正门和主要殿堂为蓝底金字或黑底金字。院门匾黑底金字。石刻门匾为白底墨字 | ref02, ref05, ref12 |
| 灯笼 | 红纱灯笼 `#d8321f`，配金色顶盖和流苏，挂在檐下，每开间一盏；宫灯为六角木框加纱 | ref02, ref07, ref09 |
| 香炉 | 殿前铜鼎，或铜质宝顶香亭（顶如亭子） | ref11 |

**尺度（清式小式和苏式园林通则，可对照本地图片核对）**
- 开间：明间 3.6–4.2 m，次间 3.0–3.6 m，梢间 2.6–3.0 m。游廊每间 2.8–3.2 m，进深 1.6–2.4 m。
- 檐柱高约等于明间宽的 0.8 倍（小式），即 3.0–3.6 m。柱径约为柱高的 1/11（0.28–0.33 m）。亭子柱高 2.8–3.2 m。
- 上檐出约为柱高的 0.3 倍，加飞椽合计 1.0–1.3 m。翼角起翘 0.3–0.6 m，平出 0.3–0.5 m。
- 举架：檐步五举（0.5），脊步七到九举（0.7–0.9），所以屋面要明显下凹。卷棚顶无正脊，用罗锅瓦圆脊。
- 台基高：主殿 0.9–1.5 m（有月台），院落正房 0.45–0.6 m，游廊 0.3 m。
- 楼阁（大观楼）：两层，下层带外廊，上层有平座栏杆；总高约 14–16 m。

## 各景点
（标注 [原著] 的出自 `research/yuanwen`；[北京] 为北京大观园景区实景；[上海] 为上海大观园）

### 正门
- [原著17] 正门五间，筒瓦泥鳅脊（卷棚），门栏窗槅细雕新鲜花样，并无朱粉涂饰，一色水磨群墙，白石台矶凿西番草花样；两边雪白粉墙，下面虎皮石。
- [北京] 朱柱，彩画檐口，灰筒瓦，红门，石阶约 5 级，汉白玉石狮一对坐在须弥座上（ref04）。实景比原著更艳丽，**以原著的“不施朱粉”为准，可参考实景的台阶和石狮比例**。
- 来源：https://commons.wikimedia.org/wiki/File:Main_gate,_Daguanyuan.jpg

### 翠嶂 · 曲径通幽
- [原著17] 白石崚嶒，或如鬼怪，或如猛兽，苔藓成斑，藤萝掩映，羊肠小径入石洞；山上镜面白石，题“曲径通幽处”。
- [上海] 中轴线上有“曲径通幽”。

### 沁芳亭 · 沁芳桥
- [原著17] 石桥三港，兽面衔吐；白石为栏，环抱池沿；桥上有亭；对联“绕堤柳借三篙翠，隔岸花分一脉香”。
- [北京] 沁芳亭为园中第一景，设在桥上（visitbeijing）。同类水亭（滴翠亭，ref03）的做法：青白石台基出水，朱柱，重檐，坐凳栏杆，可参照建模。

### 潇湘馆（林黛玉）
- [原著17] 粉垣，千百竿翠竹遮映；入门曲折游廊，石子漫成甬路；小小两三间房舍，一明两暗；后院大株梨花兼芭蕉，两间小退步；墙下引泉，开沟尺许，绕阶缘屋，盘旋竹下而出。匾“有凤来仪”，联“宝鼎茶闲烟尚绿，幽窗棋罢指犹凉”。
- [北京] “精巧纤细，雕满竹饰”，彩画用“斑竹座”冷色调（青绿竹纹）；“一带修篁，绿影婆娑”；匾“有凤来仪”。来源：https://gs.ctrip.com/html5/you/travels/1/4158352.html
- 建模：绿柱绿窗，冷色彩画（青绿为主、不贴金），竹纹装饰，院内地面铺卵石。

### 怡红院（贾宝玉）
- [原著17] 碧桃，竹篱花障月洞门；粉墙环护，绿柳周垂；两边游廊相接；院中点衬几块山石，一边芭蕉，一边西府海棠（其势若伞，丝垂翠缕，葩吐丹砂）；抱厦；室内雕空玲珑木板隔断，有玻璃大镜；后院满架蔷薇宝相。匾“怡红快绿”（原为“红香绿玉”）。
- [北京] “三开间的垂花大门楼，雕刻精美，彩饰斑斓”；有抄手游廊和三间抱厦，东西配房各三间；“金线苏彩”，贴金绘彩；隔架和花障很多。来源：https://gs.ctrip.com/html5/you/travels/1/4158352.html ，ref05（大门：极艳的苏彩，黑底金字“怡红院”匾，绿门红框，两侧绿色棂窗，白墙）。
- 建模：全园彩画最密、最艳的一处，垂花门要做垂柱和莲头。

### 蘅芜苑（薛宝钗）
- [原著17] 清凉瓦舍，一色水磨砖墙，清瓦花堵；入门即见插天大玲珑山石，四面群绕石块，把房屋全遮住，一株花木也无，只有异草（牵藤引蔓，垂檐绕柱，实若丹砂，花如金桂）；五间清厦连卷棚，四面出廊，绿窗油壁；超手游廊。匾“蘅芷清芬”，联“吟成豆蔻才犹艳，睡足酴醾梦也香”。
- [北京] “灰白游廊，走廊、窗棂全是冰裂纹”；藤本植物有紫藤、凌霄；“五间清厦”。来源：https://gs.ctrip.com/html5/you/travels/1/4158352.html ，ref01（凸碧山庄的山石上盘满藤条，可作异草的参考）。
- 建模：素净，冷灰色调，冰裂纹窗棂，水磨砖墙不刷白，游廊为灰白色。

### 稻香村（李纨）
- [原著17] 黄泥矮墙，墙头用稻茎掩护；数百株杏花，如喷火蒸霞；数楹茅屋；桑榆槿柘编成两溜青篱；土井、桔槔、辘轳；分畦列亩；石碣；竹竿挑酒幌；纸窗木榻。
- [北京] 有高大的银杏和龙爪枣；陈设简朴（“纸窗木榻结构”）。来源：https://gs.ctrip.com/html5/you/travels/1/4158352.html
- [上海] “黄泥矮墙、纸窗木榻”。

### 省亲别墅 · 顾恩思义殿 · 大观楼 · 缀锦阁 · 含芳阁
- [原著17/18] 崇阁巍峨，层楼高起，面面琳宫合抱，迢迢复道萦纡，青松拂檐，玉栏绕砌，金辉兽面，彩焕螭头；正殿匾“顾恩思义”，联“天地启宏慈，赤子苍头同感戴；古今垂旷典，九州万国被恩荣”；有月台、东阶；正楼大观楼，东面飞楼缀锦阁，西面斜楼含芳阁。
- [北京] 省亲别墅“整体仍属皇家建筑风格，但不设琉璃、丹墀，边栏以青白石为主”；顾恩思义殿“雕梁画栋，绘有龙凤和玺贴金彩画”；殿前左右各有一对铜鹿、一对铜鹤。来源：https://gs.ctrip.com/html5/you/travels/1/4158352.html
- [北京] 大观楼（ref02）：两层，朱柱，上层外廊配红色栏杆，额枋彩画浓艳，蓝底金字“大观楼”横匾，每开间挂红灯笼，下层隔扇为朱红步步锦。
- [上海] 顾恩思义殿“巍峨耸立”，悬挂原著匾联（https://m.sohu.com/a/1010196645_121792335 ）。
- 建模：用灰筒瓦，不用绿琉璃（现版本的 tileGreen 应改掉）。正殿额枋用和玺彩画（龙纹、金色多）以示与园林苏画的区别。殿前月台加铜鹿、铜鹤各一对，并加铜香亭。

### 玉石牌坊
- [原著17/18] 玉石牌坊，龙蟠螭护，玲珑凿就；灯匾原作“天仙宝境”，元妃命换“省亲别墅”。
- [北京] 青白石牌坊，高 8 m、宽 11 m；正面中额“省亲别墅”，两侧次额“芳岸”“玉津”；背面中额“国恩家庆”，两侧“云影”“波光”；阳光下金字耀目。来源：https://gs.ctrip.com/html5/you/travels/1/4033751.html ，https://gs.ctrip.com/html5/you/travels/1/4158352.html

### 沁芳闸
- [原著17] 大桥前，水如晶帘一般奔入，此桥即通外河之闸；第23回“沁芳闸桥边桃花底下一块石”。
- 建模：闸口要有跌水（白色水帘），桥边种桃树，水面漂落花。

### 蓼汀花溆
- [原著17/18/40] 水声潺湲，泻出石洞，萝薜倒垂，落花浮荡；两行垂柳杂桃杏；元宵时港上悬“蓼汀花溆”匾灯；第40回秋天：“花溆的萝港之下，觉得阴森透骨，两滩上衰草残菱”。

### 秋爽斋 · 晓翠堂（贾探春）
- [原著40] 三间屋子不曾隔断；花梨大理石大案，法帖、宝砚、笔筒，《烟雨图》，颜鲁公联“烟霞闲骨格，泉石野生涯”；元春题额里有“桐剪秋风”（院植梧桐、芭蕉）。
- [北京] 圆洞门（ref12）：白粉墙，青砖磨砖门套；门上嵌石刻横匾“秋爽斋”（白底墨字）；门扇绿色带红边，红底贴“和”“仁”斗方；墙头用瓦砌花墙。

### 藕香榭
- [原著38] 盖在池中，四面有窗，左右曲廊，跨水接岸，后有曲折竹桥；柱上黑漆嵌蚌对子“芙蓉影破归兰桨，菱藕香深写竹桥”；山坡下两棵桂花。
- 建模：对联用黑底加螺钿白字（嵌蚌），和其他金字联区分开。

### 紫菱洲 · 缀锦楼（贾迎春）
- [原著23/40] 迎春住缀锦楼；紫菱洲蓼溆一带上船。
- [上海] 紫菱洲在西南蓼溆一带，廊下有纺车（https://m.sohu.com/a/1010196645_121792335 ）。

### 栊翠庵（妙玉）
- [原著17/41/49] 山下幽尼佛寺；十数株红梅如胭脂；第41回为禅堂、耳房品茶。
- [北京] 唯一的佛寺景区，设山门和佛殿（ref11：殿前有月台和石阶，铜宝顶香亭，松柏，殿为灰瓦歇山加朱红隔扇，每开间挂红灯笼。此图可能是栊翠庵或嘉荫堂，按佛殿做法参考）。

### 凸碧山庄 · 凹晶溪馆
- [原著75/76] 山之峰脊上的敞厅，厅前平台，桌椅皆圆；下山一转即池沿，竹栏相接通藕香榭；凹晶溪馆在山怀抱中，房宇不多且矮小。
- [北京] 凸碧山庄（ref01）：朱柱，歇山加卷棚组合，蓝底金字“凸碧山庄”匾，彩画檐口，绿色栏杆，挂红灯笼；山石上盘满藤蔓。

### 芦雪广 · 暖香坞 · 蓼风轩
- [原著49/50] 芦雪广：傍山临水河滩，茅檐土壁，槿篱竹牖，推窗可钓，四面芦苇；暖香坞：夹道东西过街门，嵌石匾“穿云”“度月”。
- [北京] 有“芦雪庭”“暖香坞”景点（bendibao 列表）。
